# sanitizeString

Escapes potentially dangerous characters (`\`, `/`, `<`, `>`, `&`, `'`, `"`) in a string by replacing each with its Unicode escape written out as literal text: `<` becomes the six characters `\u003c`. Returns `null` or `undefined` unchanged if that's what was passed in.

```ts
import { sanitizeString } from '@rvoh/dream/utils'

sanitizeString('<script>alert("xss")</script>')
// '\\u003cscript\\u003ealert(\\u0022xss\\u0022)\\u003c\\u002fscript\\u003e'

sanitizeString("it's fine")
// 'it\\u0027s fine'

sanitizeString(null)
// null
```
